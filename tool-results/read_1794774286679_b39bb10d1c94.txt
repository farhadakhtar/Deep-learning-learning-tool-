    87→1. Introduction to Deep Learning
    88→
    89→1.1 What is Deep Learning?
    90→Deep Learning (DL) is the branch of Machine Learning that uses multi-layered (“deep”) artificial neural
    91→networks to learn directly from data.
    92→  ● Deep Learning is a subset of Machine Learning (ML), which itself is a subset of Artificial
    93→    Intelligence (AI).
    94→  ● It uses artificial neural networks with many hidden layers to automatically learn hierarchical
    95→    representations of raw data.
    96→  ● Unlike classical ML, DL removes the need for manual / hand-crafted feature engineering – the
    97→    network learns useful features by itself.
    98→      – Example (image recognition): early layers detect edges → middle layers detect shapes/textures
    99→         → deeper layers detect object parts → final layers recognise the whole object.

   112→1.2 Why Deep Learning Now? – The Three Enablers
   113→  ● Big Data: massive labelled and unlabelled datasets are now available (e.g. ImageNet, web-scale

   115→  ● Compute Power: GPUs / TPUs allow the huge number of matrix multiplications in deep networks
   116→    to be parallelised efficiently.
   117→  ● Algorithmic Advances: better activation functions (ReLU), optimisers (Adam, RMSProp), and
   118→    regularisation techniques (Dropout, Batch Normalisation) made very deep networks trainable.

   129→1.4 Biological Inspiration – From Neuron to Perceptron
   130→Artificial neurons are loosely inspired by biological neurons in the brain:
   131→  ● Dendrites receive electrical/chemical signals from other neurons — analogous to inputs x₁, x₂, …,
   132→    xₙ.
   133→  ● The Soma (cell body) accumulates the incoming signals — analogous to the weighted summation
   134→    Σ.
   135→  ● If the accumulated signal crosses a threshold, the neuron “fires” through its Axon — analogous to
   136→    an activation function producing an output.
   137→  ● The strength of a connection (synapse) is analogous to a weight wᵢ — learning = adjusting these
   138→    weights.

   150→2. The Perceptron
   151→
   152→2.1 Definition and Historical Note
   153→  ● Proposed by Frank Rosenblatt (1958), building on the earlier McCulloch–Pitts neuron model (1943).
   154→  ● A perceptron is the simplest artificial neuron: it performs binary classification by drawing a straight-
   155→    line (linear) decision boundary between two classes.
   156→  ● It is the fundamental building block from which larger neural networks (Multi-Layer Perceptrons)
   157→    are constructed.
   158→
   159→2.2 Mathematical Model
   160→A perceptron performs two operations in sequence — a weighted summation, followed by a non-linear
   161→activation:
   162→
   163→                          Net input:   z = w₁x₁ + w₂x₂ + … + wₙxₙ + b = ∑ wᵢxᵢ + b
   164→                   Output:    y = f(z) = 1 if z ≥ 0 ,                 0 if z < 0              (unit-step activation)
   165→
   166→
   167→
   168→
   169→Figure: Block diagram of a perceptron – inputs are weighted, summed with a bias, and passed through an activation
   170→                                                    function.
   171→
   172→Significance of each component
   173→  ● Inputs (x₁…xₙ): the numeric feature values describing the pattern to be classified.
   174→  ● Weights (w₁…wₙ): learnable parameters that decide how strongly each input influences the
   175→    output; learned from data.
   176→  ● Bias (b): shifts the decision boundary away from the origin, so the boundary need not pass
   177→    through (0,0,…).
   178→  ● Net input (z): a linear combination of inputs – geometrically, it measures the (signed) distance of
   179→    a point from the decision hyperplane.
   180→  ● Activation f(z): converts the continuous net input into a discrete class decision (0 or 1).
   181→                                       Unit 1: Introduction to Deep Learning | Page 5 of 36
   182→CCE3144 – Deep Learning                                                                       Manipal University Jaipur
   183→
   184→2.3 Geometric Interpretation – Linear Separability
   185→  ● The equation ∑wᵢxᵢ + b = 0 defines a straight line (2 inputs), a plane (3 inputs), or a hyperplane (n
   186→    inputs) that separates the input space into two half-spaces.
   187→  ● A perceptron can classify a dataset correctly only if the two classes are linearly separable – i.e. some
   188→    hyperplane can separate them completely.
   189→
   190→2.4 Perceptron Learning Algorithm
   191→Weights are learned iteratively so that the perceptron's output matches the desired target for every
   192→training example.
   193→Step 1 — Initialise
   194→  ● Set weights wᵢ and bias b to 0 (or small random values); choose a learning rate η, where 0 < η ≤ 1.
   195→Step 2 — For every training pair (x, t), where t is the target output
   196→  ● (a) Compute the net input: z = ∑ wᵢxᵢ + b
   197→  ● (b) Compute the predicted output: y = f(z)
   198→  ● (c) Compute the error: e = t − y
   199→  ● (d) Update every weight: wᵢ ← wᵢ + η·e·xᵢ
   200→  ● (e) Update the bias: b ← b + η·e
   201→Step 3 — Repeat
   202→  ● Repeat Step 2 for every example in the training set — this is one epoch.
   203→  ● Repeat over multiple epochs until an entire epoch produces zero errors (convergence), or a
   204→    maximum number of epochs is reached.
   205→
   206→    wᵢ(new) = wᵢ(old) + η (t − y) xᵢ            b(new) = b(old) + η (t − y)
   207→
   208→
   209→  Why does this update rule work?
   210→  If prediction is already correct (e = 0): no change is made — there is nothing to fix.
   211→  If target = 1 but output = 0 (e = +1): weights are increased along xⁱ, raising z next time so it is more
   212→  likely to cross the threshold and fire (output 1).
   213→  If target = 0 but output = 1 (e = −1): weights are decreased, lowering z next time so it is more likely
   214→  to stay below threshold (output 0).
   215→  Perceptron Convergence Theorem: if the two classes are linearly separable, this algorithm is
   216→  guaranteed to find a separating hyperplane in a finite number of steps.

   225→We train a single perceptron to reproduce the 2-input AND logic gate.
   226→                 x₁                        x₂                                          Target t = x₁ AND x₂
   227→ 0                           0                                     0
   228→ 0                           1                                     0
   229→ 1                           0                                     0
   230→ 1                           1                                     1

   232→
   233→Initial settings: w₁ = 0, w₂ = 0, b = 0, learning rate η = 1, activation: unit step with threshold z ≥ 0 →
   234→1.
   235→
   236→Detailed walk-through of Epoch 1
   237→Sample 1: x = (0,0), target t = 0
   238→ ● z = (0)(0) + (0)(0) + 0 = 0 → since z ≥ 0, y = 1
   239→ ● error e = t − y = 0 − 1 = −1 (wrong prediction → update needed)
   240→ ● w₁ ← 0 + 1(−1)(0) = 0, w₂ ← 0 + 1(−1)(0) = 0, b ← 0 + 1(−1) = −1
   241→     – Significance: both inputs are 0, so only the bias absorbs the correction — weights cannot
   242→        change when their input is 0.
   243→Sample 2: x = (0,1), target t = 0
   244→ ● z = (0)(0) + (0)(1) + (−1) = −1 → since z < 0, y = 0
   245→ ● error e = 0 − 0 = 0 → prediction already correct, no update
   246→     – Significance: zero error means the current weights already work for this sample — the rule
   247→        leaves them untouched.
   248→Sample 3: x = (1,0), target t = 0
   249→ ● z = (0)(1) + (0)(0) + (−1) = −1 → y = 0, error e = 0 → no update
   250→Sample 4: x = (1,1), target t = 1
   251→ ● z = (0)(1) + (0)(1) + (−1) = −1 → since z < 0, y = 0
   252→ ● error e = 1 − 0 = 1 (wrong prediction → update needed)
   253→ ● w₁ ← 0 + 1(1)(1) = 1, w₂ ← 0 + 1(1)(1) = 1, b ← −1 + 1(1) = 0
   254→     – Significance: the only positive example was misclassified as 0, so weights increase along both
   255→        active inputs, pushing z upward for this pattern next time.

   328→2.6 Limitation of the Perceptron — The XOR Problem
   329→A single-layer perceptron can only separate linearly separable classes. The XOR function is the classic
   330→counter-example:
   331→              x₁                   x₂                              Target = XOR                                         Class
   332→ 0                        0                           0                                                  Class 0
   333→ 0                        1                           1                                                  Class 1
   334→ 1                        0                           1                                                  Class 1
   335→ 1                        1                           0                                                  Class 0
   336→
   337→
   338→  ● Class 0 points {(0,0),(1,1)} and Class 1 points {(0,1),(1,0)} lie on opposite diagonals of the unit
   339→    square — no single straight line can separate them.
   340→
   341→  ● Formally: no w₁, w₂, b exist that satisfy all four inequalities implied by the XOR truth table
   342→    simultaneously (this can be shown leads to a contradiction, e.g. adding the inequalities for (0,0) and
   343→    (1,1) contradicts those for (0,1) and (1,0)).
   344→
   345→  ● This limitation, highlighted by Minsky & Papert (1969), was resolved by stacking multiple
   346→    perceptron layers — the Multi-Layer Perceptron (MLP) — trained using the Backpropagation
   347→    algorithm (Section 5).
   348→  ● XOR is not linearly separable, so a single-layer perceptron fails. It is solved by a 2-2-1 Multi-Layer
   349→    Perceptron (2 inputs → 2 hidden neurons → 1 output neuron) using a hard step (threshold) activation:
   350→
   351→(The output effectively computes h1 AND (NOT h2 ).)

   360→3. Learning and Recognition
   361→“Learning” in a neural network means automatically adjusting weights from data. “Recognition” is the
   362→use of the trained network to identify / classify new, unseen patterns. Based on the nature of the training
   363→data, learning is broadly divided into supervised and unsupervised learning.
   364→
   365→3.1 Supervised Learning
   366→  ● Training data consists of input–output pairs (X, Y), where Y is the known, correct “label” or “target”
   367→    for each input X.
   368→  ● The algorithm learns a mapping f: X → Y that minimises the difference between predicted and
   369→    actual outputs.
   370→  ● Two main task types:
   371→      – Classification: output is a discrete category (e.g. spam / not spam, digit 0–9).
   372→      – Regression: output is a continuous numeric value (e.g. house price, temperature).
   373→  ● Examples: email spam detection, disease diagnosis from labelled scans, house-price prediction, the
   374→    AND-gate perceptron of Section 2.
   375→
   376→3.2 Unsupervised Learning
   377→  ● Training data consists of only inputs X, with no associated target labels.
   378→  ● The algorithm discovers hidden structure, patterns, or groupings in the data by itself.
   379→  ● Common tasks: clustering (grouping similar points), dimensionality reduction, anomaly detection.
   380→  ● Examples: customer segmentation for marketing, grouping news articles by topic, anomaly
   381→    detection in network traffic.
   382→
   383→

   395→              Aspect                  Supervised Learning                                     Unsupervised Learning
   396→ Training data               Labelled (X, Y)                                        Unlabelled (X only)
   397→ Goal                        Learn mapping X → Y                                    Discover hidden structure
   398→ Feedback                    Direct error signal (loss)                             No explicit error signal

   405→3.4 Worked Numerical Example — K-Means Clustering (1 iteration)
   406→K-Means is a classic unsupervised algorithm that groups data into k clusters by iteratively updating
   407→cluster centroids. Consider 4 points and k = 2:
   408→  ● Points: A(1,1), B(2,1), C(4,3), D(5,4)
   409→  ● Initial centroids (chosen as first/last point): C₁ = (1,1), C₂ = (5,4)
   410→Step 1 — Assign each point to its nearest centroid (Euclidean distance)
   411→  ● A(1,1): dist to C₁ = 0.00, dist to C₂ = √[(1−5)²+(1−4)²] = √25 = 5.00 → closer to C₁ → Cluster 1
   412→  ● B(2,1): dist to C₁ = √[(2−1)²+(1−1)²] = 1.00, dist to C₂ = √[(2−5)²+(1−4)²] = 4.24 → Cluster 1
   413→  ● C(4,3): dist to C₁ = √[(4−1)²+(3−1)²] = 3.61, dist to C₂ = √[(4−5)²+(3−4)²] = 1.41 → Cluster 2
   414→  ● D(5,4): dist to C₁ = √[(5−1)²+(4−1)²] = 5.00, dist to C₂ = 0.00 → Cluster 2
   415→Step 2 — Recompute centroids as the mean of assigned points
   416→  ● Cluster 1 = {A(1,1), B(2,1)} → new C₁ = ((1+2)/2, (1+1)/2) = (1.50, 1.00)
   417→  ● Cluster 2 = {C(4,3), D(5,4)} → new C₂ = ((4+5)/2, (3+4)/2) = (4.50, 3.50)
   418→  ● Significance: each iteration pulls the centroid toward the centre of mass of its assigned points; the
   419→    process repeats until centroids stop moving (convergence) — all without ever using a target label.

   430→4.1 What Is a Loss Function?
   431→  ● A loss function L(Y, Ŷ) quantifies how far the model's prediction Ŷ is from the actual target Y —
   432→    a single number that training tries to minimise.
   433→  ● It is the objective that backpropagation differentiates and that gradient descent minimises (Sections
   434→    5 and 6).
   435→  ● Choice of loss function depends on the task: regression uses distance-based losses; classification
   436→    uses probability-based losses.

   450→4.2 Regression Loss — Mean Squared Error (MSE)
   451→For n samples with actual values yᵢ and predictions ŷᵢ:
   452→
   453→                                               MSE = (1/n) ∑ (yᵢ − ŷᵢ)²
   454→
   455→  ● Squaring is used instead of the raw error because: (i) it removes the sign so positive and negative
   456→    errors do not cancel, and (ii) it penalises large errors much more heavily than small ones (a useful,
   457→    differentiable property for gradient-based learning).
   458→
   459→Numerical Example — MSE / MAE
   460→Predicted vs actual house prices (in ₹ lakh):
   461→           Actual (y)                 Predicted (ŷ)                          Error (y−ŷ)                           Squared error
   462→ 50                              48                                 2                                       4
   463→ 60                              65                                 −5                                      25
   464→ 70                              68                                 2                                       4
   465→
   466→
   467→  ● MSE = (1/3)(4 + 25 + 4) = (1/3)(33) = 11.00
   468→  ● For comparison, Mean Absolute Error MAE = (1/3)(|2|+|−5|+|2|) = (1/3)(9) = 3.00
   469→  ● Significance: MSE (11.0) is pulled upward by the single larger error of −5, illustrating how
   470→    squaring emphasises big mistakes more than MAE does.

   472→4.3 Classification Loss — Binary Cross-Entropy (BCE)
   473→For a binary label y ∈ {0,1} and predicted probability p = P(y=1):
   474→
   475→                                      BCE = −[ y·log(p) + (1−y)·log(1−p) ]
   476→
   477→  ● This comes from Maximum Likelihood: for y=1 we want p close to 1 (loss = −log p, small when
   478→    p→1); for y=0 we want p close to 0 (loss = −log(1−p), small when p→0).
   479→
   480→Numerical Example — Binary Cross-Entropy
   481→      y (actual)           p (predicted prob.)                     Loss formula used                                        Loss value
   482→ 1                        0.90                       −log(0.90)                                                   0.1054
   483→ 0                        0.20                       −log(1−0.20) = −log(0.80)                                    0.2231
   484→ 1                        0.60                       −log(0.60)                                                   0.5108
   485→
   486→
   487→  ● Average BCE over the 3 samples = (0.1054+0.2231+0.5108)/3 = 0.2798
   488→  ● Significance: sample 3 (y=1, p=0.60) contributes the largest loss because the model was correct
   489→    but not confident — BCE rewards confident, correct predictions and punishes confident, wrong
   490→    ones very heavily.

   495→4.4 Categorical Cross-Entropy (multi-class)
   496→
   497→                          CCE = − ∑ᵢ tᵢ log(pᵢ)         (t = one-hot target, p = softmax output)
   498→
   499→Example: 3-class problem, true class = 2 (one-hot target = [0,1,0]):
   500→     Softmax output p             CCE calculation                    Loss                                    Comment
   501→ [0.2, 0.7, 0.1]                −log(0.7)                     0.357                   Good prediction (confident & correct)
   502→ [0.6, 0.1, 0.3]                −log(0.1)                     2.303                   Poor prediction (confident but wrong)
   503→
   504→
   505→  ● Only the predicted probability assigned to the true class matters — all other softmax entries drop
   506→    out because tᵢ=0 for them.
   507→
   508→4.5 Why Cross-Entropy Rather Than MSE for Classification?
   509→  ● With a sigmoid/softmax output, MSE gradients become very small (“flat”) when the prediction is
   510→    confidently wrong — learning stalls.
   511→  ● Cross-entropy's gradient with respect to the net input simplifies to (ŷ − y), which stays large
   512→    exactly when the prediction is confidently wrong — giving a strong, consistent learning signal.
   513→  ● Cross-entropy is also the theoretically correct loss under a maximum-likelihood interpretation of
   514→    classification.

   530→5. Backpropagation
   531→
   532→5.1 Why Is Backpropagation Needed?
   533→  ● A single perceptron can only learn a linear boundary (Section 2.6). Multi-Layer Perceptrons (MLPs)
   534→    stack hidden layers to model non-linear relationships.
   535→  ● But the simple perceptron rule does not say how to update weights feeding “hidden” neurons —
   536→    there is no direct target for a hidden neuron's output.
   537→  ● Backpropagation solves this: it propagates the output error backward through the network, layer by
   538→    layer, using the chain rule, to compute ∂L/∂w for every weight — including hidden-layer weights.
   539→
   540→5.2 The Chain Rule of Differentiation
   541→
   542→    If y = f(u) and u = g(x), then dy/dx = (dy/du) × (du/dx)
   543→
   544→Small example: let y = (2x+1)² and find dy/dx at x = 3.
   545→  ● Let u = 2x+1. At x=3: u = 2(3)+1 = 7, so y = u² = 49.
   546→  ● dy/du = 2u = 14     du/dx = 2
   547→  ● dy/dx = (dy/du)×(du/dx) = 14 × 2 = 28 (matches the direct formula dy/dx = 4(2x+1) = 4(7) = 28)
   548→  ● Significance: in a network, Loss depends on a weight through a chain of nested functions (weight
   549→    → net input → activation → … → Loss). Backpropagation is simply this chain rule applied
   550→    repeatedly, one layer at a time.
   551→
   552→5.3 Forward Pass and Backward Pass
   553→  ● Forward pass: inputs flow left-to-right through the network to produce a prediction; every
   554→    intermediate activation is stored for later use.
   555→  ● Backward pass: starting from the loss, gradients flow right-to-left using the chain rule, computing
   556→    ∂L/∂w for every weight.
   557→  ● Update: once all gradients are known, every weight is adjusted by gradient descent (Section 6).
   558→

   569→5.4 Complete Worked Example
   570→Network: 2 inputs → 2 hidden neurons (sigmoid) → 1 output neuron (sigmoid). Loss: L = ½(target −
   571→output)² (the ½ makes the derivative clean).
   572→
   573→
   574→
   575→
   576→                    Figure: Network and initial parameter values used throughout this worked example.
   577→
   578→  ● Inputs: x₁ = 0.5, x₂ = 0.3    Target = 1.0     Learning rate η = 0.5
   579→  ● Weights: w₁=0.2, w₂=0.4, w₃=0.3, w₄=0.1, w₅=0.5, w₆=0.6       Biases: bₕ₁=0.25, bₕ₂=0.20, bₒ=0.4
   580→  ● Sigmoid activation: σ(z) = 1/(1+e⁻ᶻ) with derivative σ’(z) = σ(z)·(1−σ(z))
   581→
   582→Step 1 — Forward Pass
   583→  ● h₁_in = x₁w₁ + x₂w₂ + bₕ₁ = (0.5)(0.2) + (0.3)(0.4) + 0.25 = 0.10+0.12+0.25 = 0.4700
   584→  ● h₁_out = σ(0.4700) = 0.6154
   585→  ● h₂_in = x₁w₃ + x₂w₄ + bₕ₂ = (0.5)(0.3) + (0.3)(0.1) + 0.20 = 0.15+0.03+0.20 = 0.3800
   586→  ● h₂_out = σ(0.3800) = 0.5939
   587→  ● o_in = h₁_out·w₅ + h₂_out·w₆ + bₒ = (0.6154)(0.5) + (0.5939)(0.6) + 0.4 = 0.3077+0.3563+0.4 =
   588→    1.0640
   589→  ● o_out = σ(1.0640) = 0.7435 ← this is the network's prediction
   590→  ● Loss L = ½(target − o_out)² = ½(1 − 0.7435)² = ½(0.2565)² = 0.0329
   591→
   592→Step 2 — Backward Pass: Output Layer
   593→Goal: ∂L/∂w₅, ∂L/∂w₆, ∂L/∂bₒ via the chain rule ∂L/∂w = (∂L/∂o_out)(∂o_out/∂o_in)(∂o_in/∂w).
   594→  ● ∂L/∂o_out = −(target − o_out) = −(1 − 0.7435) = −0.2565
   595→  ● ∂o_out/∂o_in = o_out(1−o_out) = 0.7435(1−0.7435) = 0.1907 (sigmoid derivative)
   596→
   597→                                         Unit 1: Introduction to Deep Learning | Page 17 of 36
   598→CCE3144 – Deep Learning                                                                          Manipal University Jaipur
   599→
   600→  ● δₒ (output delta) = ∂L/∂o_in = (−0.2565)(0.1907) = −0.0489
   601→  ● ∂L/∂w₅ = δₒ × h₁_out = (−0.0489)(0.6154) = −0.0301
   602→  ● ∂L/∂w₆ = δₒ × h₂_out = (−0.0489)(0.5939) = −0.0291
   603→  ● ∂L/∂bₒ = δₒ × 1 = −0.0489
   604→  ● Significance: δₒ summarises “how much the loss would change per unit change in the output
   605→    neuron's net input”. It is computed once and reused for every weight feeding that neuron.
   606→
   607→Step 3 — Backward Pass: Hidden Layer
   608→h₁ affects the loss only through o_in, so the chain extends one link further: ∂L/∂h₁_out = δₒ × w₅.
   609→  ● ∂L/∂h₁_out = δₒ × w₅ = (−0.0489)(0.5) = −0.0245
   610→  ● ∂h₁_out/∂h₁_in = h₁_out(1−h₁_out) = 0.6154(1−0.6154) = 0.2367
   611→  ● δₕ₁ = −0.0245 × 0.2367 = −0.0058
   612→  ● ∂L/∂w₁ = δₕ₁ × x₁ = (−0.0058)(0.5) = −0.0029
   613→  ● ∂L/∂w₂ = δₕ₁ × x₂ = (−0.0058)(0.3) = −0.0017
   614→
   615→  ● ∂L/∂h₂_out = δₒ × w₆ = (−0.0489)(0.6) = −0.0294
   616→  ● ∂h₂_out/∂h₂_in = h₂_out(1−h₂_out) = 0.5939(1−0.5939) = 0.2412
   617→  ● δₕ₂ = −0.0294 × 0.2412 = −0.0071
   618→  ● ∂L/∂w₃ = δₕ₂ × x₁ = (−0.0071)(0.5) = −0.0035
   619→  ● ∂L/∂w₄ = δₕ₂ × x₂ = (−0.0071)(0.3) = −0.0021
   620→  ● Significance: notice δₒ is reused (multiplied by w₅ or w₆) rather than recomputed — this reuse of
   621→    already-computed quantities, propagating backward layer by layer, is precisely what makes
   622→    “backpropagation” efficient.
   623→

   625→   Parameter                Old value   Gradient ∂L/∂w                      Update calculation                               New value
   626→ w₁                       0.2000        −0.0029                    0.2000−0.5(−0.0029)                                0.2014
   627→ w₂                       0.4000        −0.0017                    0.4000−0.5(−0.0017)                                0.4009

   644→5.5 Key Observations
   645→  ● Backpropagation does not use a different mathematical idea from the chain rule — it simply
   646→    applies it systematically, layer by layer, reusing intermediate results for efficiency.
   647→  ● The “delta” (δ) at each neuron is the essential reusable quantity: δ = ∂L / ∂(net input of that
   648→    neuron).
   649→  ● Vanishing gradient problem: the sigmoid derivative σ’(z) never exceeds 0.25. When many such
   650→    factors (each < 1) are multiplied together across many layers, the gradient reaching early layers
   651→    shrinks toward zero, making very deep sigmoid/tanh networks slow or unable to learn. ReLU
   652→    activation (Section 5.6) largely avoids this.

   677→6. Gradient Descent and Stochastic Gradient Descent
   678→
   679→6.1 Gradient Descent — Recap
   680→
   681→                                            w ← w − η · (∂L / ∂w)
   682→
   683→  ● ∂L/∂w (the gradient) points in the direction of steepest increase of the loss; moving opposite to it
   684→    (hence the minus sign) decreases the loss fastest.
   685→  ● η (learning rate) controls the step size. Too small → very slow convergence. Too large → the loss
   686→    can oscillate or diverge instead of settling at the minimum.
   687→  ● This update is applied repeatedly (iteratively) until the loss stops decreasing appreciably
   688→    (convergence).
   689→
   690→6.2 Batch, Stochastic, and Mini-Batch Gradient Descent
   691→  ● Batch Gradient Descent: computes the gradient using the entire training set before every update.
   692→    Accurate, smooth path to the minimum, but slow and memory-heavy for large datasets.
   693→  ● Stochastic Gradient Descent (SGD): computes the gradient using just one randomly chosen
   694→    training example per update. Very fast per step and the noise can help escape shallow local
   695→    minima, but the convergence path is noisy / zig-zag.
   696→  ● Mini-Batch Gradient Descent: computes the gradient over a small batch (e.g. 32 or 64 samples)
   697→    per update — a practical middle ground, and the most common choice in deep learning.
