    59→  1009→5.6 Beyond the Basics
    60→  1010→     •    Teacher forcing — during training, the true previous word is fed as input at every step (as in
    61→  1011→          Worked Example 5), even if the model's own previous prediction was wrong; this stabilises and
    62→  1012→          speeds up training.
    63→  1013→     •    Generation / sampling — at inference time there is no “true” next word, so the model's own
    64→  1014→          output is fed back as the next input. Common strategies: greedy decoding (always pick the
    65→  1015→          highest-probability word), sampling with temperature, and beam search.
    66→  1016→     •    LSTM / GRU language models — in practice, the plain-RNN recurrence in this section is almost
    67→  1017→          always replaced by an LSTM or GRU cell (Sections 3–4), since long documents need the improved
    68→  1018→          long-range memory.
    69→  1019→     •    Modern context — Transformer-based language models have largely superseded RNN-based
    70→  1020→          ones for state-of-the-art results, but the evaluation concepts introduced here — next-word
    71→  1021→          prediction, cross-entropy loss, and perplexity — remain exactly the same and are used to evaluate
    72→  1022→          Transformer language models too.

   176→  1126→     (A) Every sequence in the dataset must have exactly the same length. ✓ correct

   189→  1139→using a fixed number of parameters? [1 mark]

   244→  1194→     (A) Using too few hidden units.
   245→  1195→     (B) Using too large a learning rate.

   381→  1331→Part B — Descriptive and Numerical Questions (Q16–Q50)
   382→  1332→Q16. List and briefly explain three properties that any model of sequential data must respect. [3 marks]
   383→  1333→Solution:
   384→  1334→     •    Variable length — sequences in a dataset are rarely all the same length (sentences, audio clips,
   385→  1335→          etc.), so the model cannot assume a fixed-size input.
   386→  1336→     •    Order-dependence — shuffling the elements changes (or destroys) the meaning; e.g. “dog bites

   402→  1352→Q18. Explain the difference between the “folded” and “unrolled” views of an RNN, and state why the
   403→  1353→unrolled view is useful for training. [2 marks]
   404→  1354→Solution:
   405→  1355→     •    The folded view shows a single RNN cell with a self-loop (feedback arrow) — a compact picture
   406→  1356→          of the recurrence rule itself.
   407→  1357→     •    The unrolled view draws a separate copy of that same cell for every time step t = 1, …, T,
   408→  1358→          connected in a chain, with the identical weights (Wxh, Whh, Why) used in every copy (Figure 2).

   410→  1360→          an ordinary directed acyclic graph, to which standard backpropagation can be applied directly —
   411→  1361→          this is exactly what Backpropagation Through Time (BPTT) does (Section 2.5).

   443→  1393→Q21. In Worked Examples 1, 3 and 4, the plain RNN, LSTM and GRU each processed the identical first
   444→  1394→input x₁, yet produced three different values of h₁. Explain why, and identify which architecture's h₁
   445→  1395→depends on x₁ alone versus which involve additional learned control. [3 marks]
   446→  1396→Solution:
   447→  1397→     •    Plain RNN: h₁ = tanh(Wxh x₁ + Whh h₀ + bh) is a direct, ungated transformation of x₁ (with h₀ = 0
   448→  1398→          contributing nothing) — no learned gate decides how much of x₁ to accept.
   449→  1399→     •    LSTM: h₁ = o₁ ⊙ tanh(C₁), where C₁ = i₁ ⊙ c̃₁ already involves the input gate i₁ deciding how much
   450→  1400→          of the candidate c̃₁ to write in, and the output gate o₁ separately deciding how much of C₁ to
   451→  1401→          expose — two extra learned filters between x₁ and h₁.
   452→  1402→     •    GRU: h₁ = z₁ ⊙ h̃ ₁ (since h₀ = 0), where the update gate z₁ decides how much of the candidate to
   453→  1403→          accept — one learned filter between x₁ and h₁.
   454→  1404→     •    All three use the same raw input x₁, but the RNN applies no learned gating, while LSTM and GRU
   455→  1405→          each pass the resulting candidate through one or more sigmoid gates before it becomes h₁ —
   456→  1406→          with untrained (illustrative) weights these gates simply produce different numbers than the
   457→  1407→          ungated RNN; after training, this gating is precisely what lets LSTM/GRU learn when to accept
   458→  1408→          new information.
