   150→2. The Perceptron
   151→
   152→2.1 Definition and Historical Note
   153→  ● Proposed by Frank Rosenblatt (1958), building on the earlier McCulloch–Pitts neuron model (1943).
   154→  ● A perceptron is the simplest artificial neuron: it performs binary classification by drawing a straight-
   155→    line (linear) decision boundary between two classes.
   156→  ● It is the fundamental building block from which larger neural networks (Multi-Layer Perceptrons)
   157→    are constructed.
   158→
   159→2.2 Mathematical Model
   160→A perceptron performs two operations in sequence — a weighted summation, followed by a non-linear
   161→activation:
   162→
   163→                          Net input:   z = w₁x₁ + w₂x₂ + … + wₙxₙ + b = ∑ wᵢxᵢ + b
   164→                   Output:    y = f(z) = 1 if z ≥ 0 ,                 0 if z < 0              (unit-step activation)
   165→
   166→
   167→
   168→
   169→Figure: Block diagram of a perceptron – inputs are weighted, summed with a bias, and passed through an activation
   170→                                                    function.
   171→
   172→Significance of each component
   173→  ● Inputs (x₁…xₙ): the numeric feature values describing the pattern to be classified.
   174→  ● Weights (w₁…wₙ): learnable parameters that decide how strongly each input influences the
   175→    output; learned from data.
   176→  ● Bias (b): shifts the decision boundary away from the origin, so the boundary need not pass
   177→    through (0,0,…).
   178→  ● Net input (z): a linear combination of inputs – geometrically, it measures the (signed) distance of
   179→    a point from the decision hyperplane.
   180→  ● Activation f(z): converts the continuous net input into a discrete class decision (0 or 1).
   181→                                       Unit 1: Introduction to Deep Learning | Page 5 of 36
   182→CCE3144 – Deep Learning                                                                       Manipal University Jaipur
   183→
   184→2.3 Geometric Interpretation – Linear Separability
   185→  ● The equation ∑wᵢxᵢ + b = 0 defines a straight line (2 inputs), a plane (3 inputs), or a hyperplane (n
   186→    inputs) that separates the input space into two half-spaces.
   187→  ● A perceptron can classify a dataset correctly only if the two classes are linearly separable – i.e. some
   188→    hyperplane can separate them completely.
   189→
   190→2.4 Perceptron Learning Algorithm
   191→Weights are learned iteratively so that the perceptron's output matches the desired target for every
   192→training example.
   193→Step 1 — Initialise
   194→  ● Set weights wᵢ and bias b to 0 (or small random values); choose a learning rate η, where 0 < η ≤ 1.
   195→Step 2 — For every training pair (x, t), where t is the target output
   196→  ● (a) Compute the net input: z = ∑ wᵢxᵢ + b
   197→  ● (b) Compute the predicted output: y = f(z)
   198→  ● (c) Compute the error: e = t − y
   199→  ● (d) Update every weight: wᵢ ← wᵢ + η·e·xᵢ
   200→  ● (e) Update the bias: b ← b + η·e
   201→Step 3 — Repeat
   202→  ● Repeat Step 2 for every example in the training set — this is one epoch.
   203→  ● Repeat over multiple epochs until an entire epoch produces zero errors (convergence), or a
   204→    maximum number of epochs is reached.
   205→
   206→    wᵢ(new) = wᵢ(old) + η (t − y) xᵢ            b(new) = b(old) + η (t − y)
   207→
   208→
   209→  Why does this update rule work?
   210→  If prediction is already correct (e = 0): no change is made — there is nothing to fix.
   211→  If target = 1 but output = 0 (e = +1): weights are increased along xⁱ, raising z next time so it is more
   212→  likely to cross the threshold and fire (output 1).
   213→  If target = 0 but output = 1 (e = −1): weights are decreased, lowering z next time so it is more likely
   214→  to stay below threshold (output 0).
   215→  Perceptron Convergence Theorem: if the two classes are linearly separable, this algorithm is
   216→  guaranteed to find a separating hyperplane in a finite number of steps.

   328→2.6 Limitation of the Perceptron — The XOR Problem
   329→A single-layer perceptron can only separate linearly separable classes. The XOR function is the classic
   330→counter-example:
   331→              x₁                   x₂                              Target = XOR                                         Class
   332→ 0                        0                           0                                                  Class 0
   333→ 0                        1                           1                                                  Class 1
   334→ 1                        0                           1                                                  Class 1
   335→ 1                        1                           0                                                  Class 0
   336→
   337→
   338→  ● Class 0 points {(0,0),(1,1)} and Class 1 points {(0,1),(1,0)} lie on opposite diagonals of the unit
   339→    square — no single straight line can separate them.
   340→
   341→  ● Formally: no w₁, w₂, b exist that satisfy all four inequalities implied by the XOR truth table
   342→    simultaneously (this can be shown leads to a contradiction, e.g. adding the inequalities for (0,0) and
   343→    (1,1) contradicts those for (0,1) and (1,0)).
   344→
   345→  ● This limitation, highlighted by Minsky & Papert (1969), was resolved by stacking multiple
   346→    perceptron layers — the Multi-Layer Perceptron (MLP) — trained using the Backpropagation
   347→    algorithm (Section 5).
   348→  ● XOR is not linearly separable, so a single-layer perceptron fails. It is solved by a 2-2-1 Multi-Layer
   349→    Perceptron (2 inputs → 2 hidden neurons → 1 output neuron) using a hard step (threshold) activation:
   350→
   351→(The output effectively computes h1 AND (NOT h2 ).)

   360→3. Learning and Recognition
   361→“Learning” in a neural network means automatically adjusting weights from data. “Recognition” is the
   362→use of the trained network to identify / classify new, unseen patterns. Based on the nature of the training
   363→data, learning is broadly divided into supervised and unsupervised learning.
   364→
   365→3.1 Supervised Learning
   366→  ● Training data consists of input–output pairs (X, Y), where Y is the known, correct “label” or “target”
   367→    for each input X.
   368→  ● The algorithm learns a mapping f: X → Y that minimises the difference between predicted and
   369→    actual outputs.
   370→  ● Two main task types:
   371→      – Classification: output is a discrete category (e.g. spam / not spam, digit 0–9).
   372→      – Regression: output is a continuous numeric value (e.g. house price, temperature).
   373→  ● Examples: email spam detection, disease diagnosis from labelled scans, house-price prediction, the
   374→    AND-gate perceptron of Section 2.
   375→
   376→3.2 Unsupervised Learning
   377→  ● Training data consists of only inputs X, with no associated target labels.
   378→  ● The algorithm discovers hidden structure, patterns, or groupings in the data by itself.
   379→  ● Common tasks: clustering (grouping similar points), dimensionality reduction, anomaly detection.
   380→  ● Examples: customer segmentation for marketing, grouping news articles by topic, anomaly
   381→    detection in network traffic.
   382→
   383→

   405→3.4 Worked Numerical Example — K-Means Clustering (1 iteration)
   406→K-Means is a classic unsupervised algorithm that groups data into k clusters by iteratively updating
   407→cluster centroids. Consider 4 points and k = 2:
   408→  ● Points: A(1,1), B(2,1), C(4,3), D(5,4)
   409→  ● Initial centroids (chosen as first/last point): C₁ = (1,1), C₂ = (5,4)
   410→Step 1 — Assign each point to its nearest centroid (Euclidean distance)
   411→  ● A(1,1): dist to C₁ = 0.00, dist to C₂ = √[(1−5)²+(1−4)²] = √25 = 5.00 → closer to C₁ → Cluster 1
   412→  ● B(2,1): dist to C₁ = √[(2−1)²+(1−1)²] = 1.00, dist to C₂ = √[(2−5)²+(1−4)²] = 4.24 → Cluster 1
   413→  ● C(4,3): dist to C₁ = √[(4−1)²+(3−1)²] = 3.61, dist to C₂ = √[(4−5)²+(3−4)²] = 1.41 → Cluster 2
   414→  ● D(5,4): dist to C₁ = √[(5−1)²+(4−1)²] = 5.00, dist to C₂ = 0.00 → Cluster 2
   415→Step 2 — Recompute centroids as the mean of assigned points
   416→  ● Cluster 1 = {A(1,1), B(2,1)} → new C₁ = ((1+2)/2, (1+1)/2) = (1.50, 1.00)
   417→  ● Cluster 2 = {C(4,3), D(5,4)} → new C₂ = ((4+5)/2, (3+4)/2) = (4.50, 3.50)
   418→  ● Significance: each iteration pulls the centroid toward the centre of mass of its assigned points; the
   419→    process repeats until centroids stop moving (convergence) — all without ever using a target label.

   430→4.1 What Is a Loss Function?
   431→  ● A loss function L(Y, Ŷ) quantifies how far the model's prediction Ŷ is from the actual target Y —
   432→    a single number that training tries to minimise.
   433→  ● It is the objective that backpropagation differentiates and that gradient descent minimises (Sections
   434→    5 and 6).
   435→  ● Choice of loss function depends on the task: regression uses distance-based losses; classification
   436→    uses probability-based losses.
   437→
   438→
   439→
   440→
   441→ Figure: The loss function sits at the centre of the training loop: it compares prediction with ground truth and drives
   442→                                                   every weight update.
   443→

   445→
   446→

   448→CCE3144 – Deep Learning                                                                         Manipal University Jaipur

   450→4.2 Regression Loss — Mean Squared Error (MSE)
   451→For n samples with actual values yᵢ and predictions ŷᵢ:
   452→
   453→                                               MSE = (1/n) ∑ (yᵢ − ŷᵢ)²
   454→
   455→  ● Squaring is used instead of the raw error because: (i) it removes the sign so positive and negative
   456→    errors do not cancel, and (ii) it penalises large errors much more heavily than small ones (a useful,
   457→    differentiable property for gradient-based learning).
   458→
   459→Numerical Example — MSE / MAE
   460→Predicted vs actual house prices (in ₹ lakh):
   461→           Actual (y)                 Predicted (ŷ)                          Error (y−ŷ)                           Squared error
   462→ 50                              48                                 2                                       4
   463→ 60                              65                                 −5                                      25
   464→ 70                              68                                 2                                       4
   465→
   466→
   467→  ● MSE = (1/3)(4 + 25 + 4) = (1/3)(33) = 11.00
   468→  ● For comparison, Mean Absolute Error MAE = (1/3)(|2|+|−5|+|2|) = (1/3)(9) = 3.00
   469→  ● Significance: MSE (11.0) is pulled upward by the single larger error of −5, illustrating how
   470→    squaring emphasises big mistakes more than MAE does.
   471→
   472→4.3 Classification Loss — Binary Cross-Entropy (BCE)
   473→For a binary label y ∈ {0,1} and predicted probability p = P(y=1):
   474→
   475→                                      BCE = −[ y·log(p) + (1−y)·log(1−p) ]
   476→
   477→  ● This comes from Maximum Likelihood: for y=1 we want p close to 1 (loss = −log p, small when
   478→    p→1); for y=0 we want p close to 0 (loss = −log(1−p), small when p→0).
